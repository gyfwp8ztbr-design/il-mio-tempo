# Il mio tempo

App personale per programmare il tempo per ruolo: serbatoio giornaliero, attività previste e reali, micro-attività in parallelo, collegamento a Google Calendar.

- I dati (attività, orari) restano nella memoria del dispositivo; nel codice non c'è nessun dato personale né chiave segreta.
- Il codice cliente Google si inserisce dentro l'app, da Impostazioni.
